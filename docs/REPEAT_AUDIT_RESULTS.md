# 하루 전력곡선 반복의 특징과 예측 평가 — 2026-10-06

## 질문과 결론

96개 15분 전력값이 모두 같은 날짜를 묶고, 그 날짜들의 다른 기록과 기존 예측 결과를 비교했다. **반복되는 전력곡선에 생산량·날씨까지 동일하게 붙어 있지는 않다.** 반복은 1~6월에 집중되며 7월 이후 크게 줄어든다. 따라서 계절 변화만으로 모델 실패를 설명하면 부족하다. 원자료 생성/증강/결합 과정은 미확인이고 반복 원인을 확정할 수 없다.

## 방법과 데이터 보존

- 원본 `data/original.csv`는 변경하지 않았다. 원본 SHA256: `8f7af2e49366c93e1d6f5fdef4b5e350066c1792ac463c2c2886e370f4674830`.
- 날짜별 원본 행 순서의 24행 × 4분기 값을 정확 비교했다. 비슷한 모양, 일평균 일치, 반올림 비교가 아니다. 각 날짜에 96값이 있다.
- 7/13·7/15의 시간 오류는 전체 반복 감사에서는 원본 행 순서로 보존하며 표시했다. 예측 성능은 기존 타깃 제외 규칙을 유지한다. 결측은 비교에서 같은 위치의 NaN끼리 동일하게 취급하고 통계는 관측값만 사용한다. 값을 보간하거나 이상치를 제거하지 않았다.

- 257일 중 142곡선, 반복45그룹에 속한 날짜160일, 그룹당 하나만 남길 경우 추가115일이다. 160일과 115일은 다른 셈이다. 같은 그룹 내부의 날짜 조합은302쌍이다.

### 예시 1: 가장 큰 15일 그룹

1/5·6·12·13·19·20·26·27·31, 3/5·12·19·26·31, 5/30의 전력96값이 모두 같다. 모든 날짜의 생산량기록과 인원기록은0이고 전력 일평균21.9375, 최대26이다. 일평균 기온은 -3.42~19.24로 다르다. **생산 미기록/무생산 상태의 저부하 반복**이라는 설명 후보가 있지만 실제 휴무나 대기전력이라는 현장 사실은 확인되지 않았다.

### 예시 2: 생산 기록이 있는 연속 반복

4/12~16와5/18의 전력96값은 모두 같다(일평균123.4792, 최대182). 그러나 생산량기록 일합계는16,126~23,411이고 생산량>0인 시간은15~24시간이다. 따라서 모든 반복을 비가동일로 설명할 수 없다.

### 예시 3: 7월의 두 날짜

| 전력96값 | 두 날짜 모두 완전히 같음 | 두 날짜 모두 완전히 같음 |

생산량기록이 거의 절반으로 달라도 전력96값은 같다. 이는 자료의 연계와 생성 방식을 확인해야 한다는 근거이지 생산량이 전력에 영향을 주지 않는다는 증거가 아니다.

## 연구에 반영할 결정

1. 날씨/생산량 추가 효과가 작다는 결과를 모델 체급 부족만으로 설명하지 않는다. 전력과 부가정보의 연계 문제도 경쟁 가설로 유지한다. 실제 인과 요인이라는 문구를 쓰지 않는다.
2. 월별 일반 성능과 반복 유무 사후 성능을 함께 보이고 기존 반복제거 학습 민감도를 유지한다. 동일 패턴 제거는 원본 수정이나 독립성 확보를 뜻하지 않는다.
3. 연구 본체는 **최근 관측된 전력으로 준비시간 이후의 고부하 진입을 예측하는 제한적 의사결정**에 둔다. 생산·날씨 조건별 오류 분석은 계속하되 가동계획 최적화와 실제 절감을 검증했다고 쓰지 않는다.
4. 다음 실험은 기존 재정의 문서의 A(준비시간45~120분 사건/확률보정)와 B(후보시점 차이·불확실성) 범위로 제한한다. 이번 감사로7월을 다시 성공범위 선택에 이용하지 않는다. 독립 여름자료와 데이터 생성 메타정보의 확보가 별도 필요하다.
