# 공식 배점과 후속 실험 설계 — 2026-10-02

출처: 사용자가 제공한 서면평가표 이미지 및 ⑤ 과제 공지. 배점은 데이터 이해·진단 15, AI 예측모델 40, 영향요인·오류분석 15, 현장 활용 10, 창의성·차별성 10, 코드·재현성 10점이다. 기존 문서의 보고서 분량 비율은 편집 가이드이며 공식 배점이 아니다.

## 보고서·발표의 명시적 답변 구조

| 공식 항목 | 제출물에서 바로 찾을 증거 |
|---|---|
| 데이터 이해 15 | 생산단위·변수 의미·시간/설비/제품 관계의 확인/미확인 구분, 시간축·결측·중복·이상치 처리와 민감도 |
| 모델 40 | 다음날 96구간 예측, 기준 포함 다중모델 비교, 특징공학 ablation, 시간 검증, 모델 선정 이유, 한계 |
| 요인·오류 15 | 생산·인원·시간 조건별 오류와 피크 발생률, 상호작용, FN/FP 수와 분모, 표본 일수 |
| 활용 10 | 예측 시점→담당자 판단→제약부 이동→실제값 평가, 실패·보류조건과 현장 확인사항 |
| 차별성 10 | 검증된 피크 저감을 요금·노동비 의사결정으로 연결, 불확실성 대응은 추가 검증된 경우에만 주장 |
| 재현 10 | 원본부터 전처리·학습·추론·결과까지 실행 명령, 고정 환경, 제출 예측파일, 실행 검증 |

각 절은 ‘요구 질문→결론→수치/그림→한계’로 작성한다. 회귀 과제와 공통표의 이상확률/F1 문구를 구분한다. 주 과제는 전력값 회귀이며 학습 전력의 95백분위 초과를 보조 위험사건으로 정의하여 구간/일 수준 F1·FN·FP를 병기한다. 이는 물리적 설비 한계나 보정된 이상확률이 아니다. 배점표의 확률 요구와의 해석 차이는 최종 보고서에서 밝힌다.

## 이번 작업 범위

1. 기존 선택 F2/LGB_medium을 그대로 복원하고 과거 저장 성능과 일치 검사. 재선택·전체 탐색 반복 없음.
2. 학습구간 3분위 경계로 생산량·인원·온도 구간 정의. 테스트는 사후 해석만 수행. 시간대×생산, 생산×인원 조건을 모두 공개하고 유리한 조합만 선별하지 않음.
3. 평균오차, 편향, TP/FN/FP/TN, 재현율·정밀도·F1, 피크 빈도·표본 수·일수 보고. 분모 0은 결측으로 표시. 일 단위 paired bootstrap은 반복 패턴·시계열 의존 및 다중비교 한계가 있는 기술통계.
4. 후속 운영 시뮬레이션: 이미 테스트를 본 뒤 설계되었으므로 추가 탐색 분석이며 새로운 독립 최종검증으로 표현하지 않음.

## 피크 저감 시뮬레이션: 조건부 비율 이동

예측벡터 p에 대해 각 구간에서 최대 f(0/5/10/15%)를 같은 날 ±30/60분 이내로 이동하여 예상 일최대값을 최소화한다. 동률이면 이동량을 최소화한다. 이동을 구간별 비율행렬 R로 고정한 뒤 실제 부하 y에 Ry를 적용한다. R은 예측만으로 결정되며 실제값으로 다시 최적화하지 않는다. 기준예측·AI·실제값을 미리 아는 oracle 참고는 동일 제약/조정기를 사용한다. f=0이 무조정이다.

이는 **각 구간의 실제 부하를 예측 단계에서 정한 비율대로 분할·이동할 수 있다**는 강한 가정이다. 실제 설비 작업 단위·선후공정·재기동·이동에 따른 효율 변화·수신 설비 한계·납기는 관측되지 않았다. 앞당기기도 포함하므로 실시간 측정 뒤 명령하는 제어기가 아니다. 실제 생산계획의 확정 가능성이나 생산량 보존을 입증하지 않는다. 에너지 총량 보존은 15분 동일 간격·단위 고정 가정 아래의 수학적 보존이다.

각 열 합 1, 비음수, 이동범위, 원구간 반출률 상한, 일 총량을 검사한다. 평균 일최대 감소와 전체 기간 최대 감소를 구분하며 악화일·이동량·예측한 감소와 실제 감소를 함께 공개한다. oracle는 이 가정 아래의 참고 상한이며 실제 달성 가능한 공장 상한이 아니다. 단위 미확인이므로 원자료 단위로 보고하고 원화 환산하지 않는다.
