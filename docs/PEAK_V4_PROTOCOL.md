# 추가 개선 가설 H4~H5: 결과 확인 전 고정

2026-10-02. 사용자의 추가 요청: 실패 결론으로 보고서 본문을 확정하지 말고, 기준보다 나은 방법을 깊게 검토하여 계속 연구한다. 이에 최초 최대 5개 가설 범위 안에서 H4/H5를 추가한다. 기존 H1~H3 실패 원자료는 보존한다. 보고서와 경제성·일정 결론 확정은 보류한다.

## 실패 구조와 두 가설

기존 결합은 생산기록 양수 확률 p>=0.5에서 p×양수전문가+(1-p)×0기록전문가의 조건부 평균을 쓴다. 양수 확률이 높아도 낮은 상태와 평균내어 피크가 줄어든다. 제곱손실은 분포 꼬리에 민감하며 평균 MAE 목적과 일치하지 않는다. 피크 가중만으로 이 구조를 바꾸지 못했다.

- **H4 조건부 중앙값 전문가:** 기존 B1 상태분류기와 임계0.5를 그대로 두고, p>=0.5이면 양수기록 자료에서 절대오차 손실로 학습한 LGB_medium 전문가를 사용한다. p<0.5는 기존처럼 전주 기준. 다봉 분포의 서로 다른 상태를 평균내는 축소를 피하고 MAE에 맞는 중앙값을 학습한다. 상태 정답은 훈련 자료에만 사용한다. 이론적으로 전체 혼합분포의 정확한 중앙값과 같다고 주장하지 않는다. 설정은 기존350나무/31잎/80최소표본/0.035학습률 그대로, objective=regression_l1만 변경한다.
- **H5 과거 하루 모양 검색:** 96구간을 독립 평균내지 않고 완료된 과거일의 온전한 곡선을 유사일 예측으로 사용한다. 훈련일의 ‘발행 시점 특징’과 검증일 특징을 비교한다. 특징은 요일 sin/cos, holiday, recent24_mean, recent7_mean, recent24_max, ctx_production_mean_24, ctx_zero_fraction_24, ctx_day_power_ratio. 훈련표본 중앙값/IQR로 표준화하고 누락은 훈련 중앙값으로 대체, 1-nearest-neighbor(거리동률은 최근날). 과거 선택 곡선에 현재/검색일의 발행시점 recent24_mean 비율(0.5~1.5 제한)을 적용한다. k=1은 실제 하루 형태와 최대치를 보존하려는 가설이며 k/특징/상한 탐색을 하지 않는다. 과거 y곡선은 훈련 cutoff 이전 완료된 날만 후보. 최근 유사한 날이 없으면 실패할 수 있다.

## 검증·채택·반대 검토

- 4/5/6월 expanding 월 검증, 동일 91일/8,736구간. H4/H5 각각 기준함수와 동일 cutoff, 최신관측<=D-1 16:00. 7월 진단은 판정 JSON을 저장한 뒤 단1회 실행, 설정 변경 금지. 8~9월 미사용.
- 기존결합 대비 평균 MAE 비증가, 일최대 MAE 감소, 피크일 재현율 증가, 구간 피크재현율 비감소를 **모두** 요구한다. 추가로 전주 기준과 모든 지표를 표시한다. 전주 기준보다 모든 지표가 우월하다는 주장은 실제로 충족할 때만 한다.
- MAE/RMSE/일최대 MAE/구간·일 재현율/정밀도/F1/과소예측/월별 결과, 일별 paired bootstrap을 저장한다. 채택은 탐색 채택이며 새 독립기간 검증이 필요하다.
- H4는 상태 오판시 과대예측, H5는 반복 데이터 암기 및 불안정한 배율 가능성을 반대 검토한다. H5의 검색일/거리/배율을 모두 저장한다.
- 실패하면 같은 4~6월이나 7월 결과에 맞춘 재조정을 하지 않는다. 누적5개 가설 종료 후 데이터가 허용하는 성과와 남은 한계를 보고한다. 새 독립 데이터 확보 없이 성공을 보장할 수 없다.
- 각 가설을 별도 브랜치 커밋/푸시한다. 실행 `python -X utf8 peak_v4.py H4` / `H5`.
