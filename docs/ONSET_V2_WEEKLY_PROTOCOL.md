# 毎週: 경보 기준 갱신 사전 계획
## 목적
월 고정 경보 기준과 매7일 갱신을 비교하여 이전 경보 보정의 월별 불안정을 줄일 수 있는지 검증한다. 모델 체급 개선과 다른 문제다.

- LightGBM F0 모델, 월초 확률보정, 월별 고부하q95는 기존 v2와 동일하게 고정한다.
- 고정 목표1%/5%, 전주 기준에도 동일 갱신 적용. 준비시간 조건 없음.
- 매월1일00:00 및7일 간격(8일/15일/22일/29일)에 지난14일 기록을 이용한다. 미래2시간 정답이 갱신시각보다 엄격히 이전인 기록만 사용한다. 음성30개 미만이면 월초 기준을 유지한다.
- 현재월이 진행된 뒤 확인된 과거 정답을 다음 갱신에 이용하는 것은 허용되지만, 아직 확인되지 않은 정답은 이용하지 않는다. 임계값은 다음 갱신 전까지 고정한다.
- 개발 성공: 4~6월 합산에서 재현율을 떨어뜨리지 않고 오경보율을 낮추거나 그 역으로 개선하고, 각 개발월의 재현율 하락은5%p 이하. 한 항목이라도 충족하지 못하면 성공으로 표현하지 않는다. 기준 선택/유리한 비용 가정 없음.
- 7월은 탐색 진단이며 선택에 사용하지 않는다. 8~9월은 이번에 사용하지 않는다.
- 정시별 TP/FP/FN/TN·재현율·정밀도·FPR 및 실제 사건별 적용/탐지 결과 모두 보고한다. 점수 순위/AP가 달라진 모델 실험으로 표현하지 않는다.
- 기존 확률/월고정5%경보 재현, 미래 정답·점수 교란에 대한 갱신기준 불변, 모든 갱신의 정답확정 경계 검증이 완료 기준.
- 신규 외부 자료 없음. 원본 불변/기존 모델 및 결과 보존. 한글 비교 그림을 렌더 확인한다.
- 실행 python onset_v2.py → python onset_v2_weekly.py. 출력 outputs/onset_v2_weekly.
