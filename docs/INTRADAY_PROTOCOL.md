# 매시간 갱신 1~2시간 전력예측: 사전 실험 계획
작성: 2026-10-06 KST. 사용자 승인에 따른 새 문제 정의. 상태: 계획만 저장, 구현/학습/시뮬레이션 미실행.
기준 커밋: 106ba0c7e8bf084d49d120a1d1d8d703340b7bbd. 브랜치 experiments/intraday-v1.

## 목적과 범위
매시간 갱신되는 기록으로 향후 1~2시간의 15분 전력값 및 고부하를 예측한다. 사전에 조정 가능하다고 확인된 작업이 있다는 조건에서 시작 시점 변경의 효과를 평가한다. 기존 하루전 실험을 덮어쓰거나 다른 예측기간의 점수를 직접 비교하지 않는다. 새 성능 수치는 아직 없다.

## 시간 계약
- 매 정시 t에 종료시각 <= t인 시간별 기록만 사용. 15/30/45/60 열은 구간 종료시각으로 통합. 60분은 다음 정시.
- 예측 대상은 종료시각 t+15,...,t+120분의 8개 값. 첫 4개/뒤 4개를 별도 평가.
- 시간열 의미와 업로드 지연 미확인. 기본 0분 지연, 60분 지연 민감도를 별도 실행. 뒤늦게 제공되는 생산량/날씨/인원을 t에 알았다고 가정하지 않도록 가용시각 명시.
- 미래 달력 외 미래 실측 생산량·기온·습도·인원 사용 금지. 전력 평균도 종료된 시간 기록만 허용.
- 학습 샘플의 모든 타깃 종료시각이 학습 절단시각 이하이어야 함. 입력/정답 겹치는 경계 샘플 제거.
- 각 발행시각의 8개 예측을 저장하고 나중 예측으로 소급 대체하지 않음. 동일 실제값이 여러 horizon에 등장하는 것을 독립 표본으로 세지 않음.

## 데이터 처리
원본 불변, 기존 해시 확인. 7/13·7/15의 시간 추정 보정은 사실이 아닌 가정: 해당 타깃 제외, 과거 입력 오염 마스킹. 제외/결측 이력 저장.
트리는 결측 분기, Ridge는 학습 구간 중앙값+결측 지시자. 미래방향 보간 금지. 0 전력/0 생산과 극단 부하는 기본 보존.
시간별 인원 소수값과 전력 단위 미확인 유지. 생산량>0은 기록상 상태이며 설비 가동 정답이 아님.
반복 일패턴은 전체 및 과거 동일패턴 유무별 사후 진단. 중복그룹의 학습 제거 민감도도 실행하되 본 평가와 구분. 동일패턴 여부는 미래 입력/운영 선별에 사용 금지.

## 비교와 피처
기준 4종: 마지막 15분값 유지, 직전 1시간 평균 유지, 전일 동일구간, 전주 동일구간. 결측 대체는 과거만 사용하고 적용횟수 보고.
회귀 후보: Ridge, LightGBM L2, CatBoost RMSE. 직접 다중시점 예측(시점별 모델 또는 horizon 입력의 pooled 모델 중 구현 전에 하나 고정).
피처 절제 비교:
F0 미래 달력 + 종료된 최근 전력 8구간 + 전일/전주 해당구간;
F1 F0 + 과거 1/3/6/24시간 평균/최대/표준편차/기울기/최근 상승폭;
F2 F1 + 마지막 관측 생산량/기온/습도/인원 및 최근 변화, 결측·경과시간 표시.
각 모델 큰 튜닝 없이 같은 세 집합 비교. 하이퍼파라미터/seed/버전은 실행 전 manifest에 저장. 미래값 교란 후 입력/예측 불변 검사.
고부하 기준 c는 각 fold 학습 전력 95백분위로 고정하며 물리적 위험/계약한도로 표현하지 않음.
회귀 임계값 방식과 직접 고부하 분류(각 구간 및 향후 2시간 중 한 번 이상)를 구분. 분류 확률은 Brier/신뢰도와 PR 지표로 평가.
고부하 진입(현재 <=c, 미래 >c)을 기존 고부하 지속과 별도 보고하여 단순 지속의 높은 탐지율에 속지 않도록 함.

## 검증과 선택
1~3월 초기학습, 4/5/6월 expanding 월별평가. 각 월 시작에 재학습하고 해당 월 모델은 고정, 입력만 매시간 갱신.
분류 경계 조정은 해당 평가월 이전의 시간순 내부 검증만 사용. 오경보율 목표 5%에서 재현율 비교 및 PR 전체곡선 보고; 고정0.5도 보조 제시. 목표달성 불가/양성부족은 명시.
4~6월 pooled MAE 최저 회귀를 선택하되 1% 이내는 단순 피처 우선. 월별/시점별 지표도 전부 남김. 모델이 기준을 못 이기면 기준 유지.
7월은 고정 구성의 스트레스 재평가. 이미 연구에 사용된 자료이므로 독립 테스트 아님. 8~9월도 미사용 테스트라고 부르지 않고 이번 1차 선택에는 사용하지 않음.
지표: 15~120분 각각 및 1/2시간 MAE/RMSE/bias, 2시간 최대 MAE/과소예측, 구간/진입/2시간 사건 recall·precision·FP, 확률 Brier, 발행횟수/고부하 수.
일단위 paired bootstrap CI + 주단위 블록 민감도. 7월 한 달 결과로 재튜닝 금지. 지표개선과 의사결정개선을 분리.

## 실패 조건과 후속 방향
시점별, 월별, 최근 기록상 생산 유무, 최근 부하 상승/하락, 관측 기온대, 결측/지연, 반복패턴별 오차·FN/FP를 비교. 조건의 기준은 학습자료에서 정의하고 표본수를 함께 표시. 미래실제생산은 사후 원인탐색용으로만 구분.
첫 후보군이 기준 대비 유용하지 않으면 1시간 범위의 고부하 진입 경보를 보조 후보로 검토한다. 유리한 구간만 골라 본래 과제를 해결했다고 하지 않으며 전체 전력 회귀 결과/실패도 남긴다. 수치만으로 선별하지 말고 실행 준비시간(30~60분)에 맞는지 확인한다. 개선 보장 없음.
1차 비교 결과 후 원인에 근거한 추가 가설 최대2개를 별도 사전기록. 무제한 탐색 금지.

## 조건부 의사결정 시뮬레이션
예측 검증 뒤 구현. 실제 설비별 작업·유연성·정격전력 정보 없음: 합성 작업 시나리오임을 명시.
먼저 고정된 가상 작업의 도착/출력/지속시간/허용 시작창/마감/용량/준비시간을 미래실측과 무관하게 정의. 원래 부하에 포함된 작업을 식별할 수 없으므로 원부하 일부를 실측 미래값으로 잘라 이동하는 것을 실제 운영정책으로 쓰지 않음.
관측 배경부하 위에 같은 추가 작업을 배치하는 반사실 시나리오를 우선하며 원공장 실측 총부하의 실제 저감이라고 부르지 않음. 작업 크기는 학습 기준의 5/10% 등 고정 가정으로 실행 전 확정.
0/30/60분 지연을 비교, 과거로 소급 이동 불가. 작업 완료가 2시간 예측창을 넘으면 연장 예측 또는 해당 후보 불허; 경계 밖 피크 누락 금지.
매시간 재계획하되 시작된 작업은 고정, 작업 중복 이동·중복 절감 집계 금지. 전일/기간 단위 누적 장부로 반동피크·최대·미완료 검사.
동일 작업/제약으로 즉시시작·기준예측·선택모델·완전예측 참고 비교. 무작업 원부하와 공정하게 구분.
평균 저감, 최대 저감/증가, 악화일 비율, 지연시간, 완료율을 모두 보고. 요금/임금은 이 뒤 조건부 적용.
