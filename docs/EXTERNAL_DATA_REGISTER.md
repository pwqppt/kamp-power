# 외부데이터·정책자료 활용 대장

대회 제공 데이터 외의 자료를 실제 분석에 사용하기 전에 이 표에 기록한다. 외부자료는 공개 접근 가능한 것만 사용하며, 링크·시행일·열람일을 보존한다. 예측모델 학습에는 현재 외부자료를 사용하지 않는다.

## 결과보고서 기재 형식

각 외부자료마다 다음을 함께 쓴다.

1. **활용 사유:** 제공 데이터만으로 알 수 없는 어떤 의사결정 값을 보완했는가.
2. **활용 방법:** 어느 수식·시나리오·표에 넣었고 어떤 전처리나 단위 변환을 했는가.
3. **출처:** 기관, 문서명, URL, 시행일 또는 기준일, 열람일.
4. **영향 범위:** 예측모델 입력인지 사후 비용 환산인지 구분하고, 결과가 얼마나 달라지는지 민감도를 제시한다.
5. **공개 가능성:** 공개 원문인지 확인하고 재배포가 제한된 원문 파일은 저장소에 복제하지 않는다.

현재 외부자료는 모두 사후 정책·비용 해석에만 쓰인다. 따라서 모델 성능 향상이나 피크 원인 발견이 외부자료 덕분이라고 주장하지 않는다.
