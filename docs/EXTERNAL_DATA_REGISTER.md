## 결과보고서 기재 형식

추가 기록 EXT-004: Python `holidays==0.105`, `holidays.KR(years=[2020,2021])`. 활용 사유는 휴일과 휴일 다음 날의 부하 패턴 차이를 사전 달력 특징으로 표현하기 위함. 활용 방법은 `holiday`, `after_holiday` 생성 및 시간대 조건 진단이며 F0부터 모델 입력에 포함된다. 출처는 https://pypi.org/project/holidays/0.105/ 및 설치 패키지의 한국 달력 구현. 2026-10-02 코드 점검에서 사용을 확인했으며 공식 2021 공휴일 달력과의 대조는 미완료. 실행시 고정 버전을 설치하며 외부 원문 데이터 파일을 재배포하지 않는다. 최종 보고서 전에 라이선스·달력 정확성 확인 필요. 기존 ‘외부자료 모델 미사용’의 포괄적 표현을 이 항목으로 정정한다.

각 외부자료마다 다음을 함께 쓴다.

1. **활용 사유:** 제공 데이터만으로 알 수 없는 어떤 의사결정 값을 보완했는가.
2. **활용 방법:** 어느 수식·시나리오·표에 넣었고 어떤 전처리나 단위 변환을 했는가.
3. **출처:** 기관, 문서명, URL, 시행일 또는 기준일, 열람일.
4. **영향 범위:** 예측모델 입력인지 사후 비용 환산인지 구분하고, 결과가 얼마나 달라지는지 민감도를 제시한다.
5. **공개 가능성:** 공개 원문인지 확인하고 재배포가 제한된 원문 파일은 저장소에 복제하지 않는다.

EXT-001~003은 사후 정책·비용 해석에 쓰이며 EXT-004는 달력 특징 생성에 사용한다. 정책자료 덕분에 예측성능이 향상됐다고 주장하지 않는다.
