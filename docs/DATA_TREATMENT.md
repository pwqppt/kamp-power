# 결측치·이상치 처리와 결과 영향

## 처리 기록
원자료 결측은 풍속 3행, 강수량 1행, 공장인원 17행이다. 전력 4개 열에는 결측이 없었다. 값 0은 결측으로 간주하지 않았다.

7/13·7/15의 시간 48행이 정상적인 0~23 순서와 달랐다. 하루 24행임을 확인하고 행 순서로 시간축을 복원했으나, 복원은 가정이므로 이 날짜의 타깃을 제외하고 이 날짜를 참조하는 과거 전력은 결측 처리했다. 따라서 주모델의 결측은 원자료 전력 누락보다 이 제외 정책에서 발생한다. 보정 목록은 hour_repair_audit.csv.

피크 자체가 연구 대상이므로 큰 전력값을 기계적으로 지우거나 자르지 않았다. 음수/단위/계측 오류와 통계적 극단값을 구분해야 한다. 공장인원에는 소수가 많아 실인원 수로 해석하지 않으며 인건비 열 1/1.5를 실제 시급으로 쓰지 않는다.

주모델 LightGBM은 결측을 별도 분기로 학습한다. 대체 실험의 중앙값·절단 경계는 학습자료에서만 산출했다. 전력 타깃 상위 1% 절단은 권장 처리가 아니라 피크 손실을 확인하는 비교 실험이다.

## 사후 민감도 결과
| 처리 | 테스트 MAE | 피크일 재현율 |
|---|---:|---:|
| 기본: 결측 자체 처리, 피크 보존 | 27.844 | 65.4% |
| 학습 중앙값 대체+결측 지시자 | 27.283 | 65.4% |
| 0 대체+결측 지시자 | 26.710 | 73.1% |
| 결측 있는 학습행 제외 | 27.342 | 57.7% |
| 입력 1~99% 경계 절단 | 27.908 | 65.4% |
| 타깃 상위 1% 절단: 부정적 영향 확인용 | 27.548 | 53.8% |
| 학습의 동일 일별 패턴 중복 제거 | 27.752 | 65.4% |

MAE가 조금 좋아져도 피크일 재현율이 나빠질 수 있다. 특히 타깃 절단은 MAE만 보면 개선이나 피크일 재현율은 약 11.5%p 하락했다. 테스트를 보고 기본 처리법을 바꾸지 않는다.

과거 전력 관련 입력에 무작위 결측을 1/5/10% 추가하면 MAE는 28.116/29.378/30.938로 증가했다. 10% 결측에서 기본 대비 약 11.1% 악화다. 이는 단일 난수 시드의 무작위 누락 시험이며, 장시간 센서 단절처럼 연속적인 누락에 대한 안전성을 증명하지 않는다.

추가 생산·기상 이력을 포함한 F4의 원자료 결측 대체 비교는 raw_missingness_sensitivity.csv에 분리했다. 이 실험을 주모델 F2의 결과와 혼동하지 않는다.
