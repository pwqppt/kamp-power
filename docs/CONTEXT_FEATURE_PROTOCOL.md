# 컨텍스트 피처·상태 조건부 모델 비교 v2

2026-10-02, 사용자 요청에 따른 별도 탐색. 기존 8~9월 결과를 보고 제안했으므로 새 독립 검증으로 표현하지 않는다. 기존 main 모델은 교체하지 않는다.

## 가설과 피처 그룹

- B0: 기존 F2, 같은 시각 과거 전력과 달력·최근 요약.
- B1: B0 + 최근 6/24/72시간 가동 대리값. 생산 0 비율·최근 생산량/인원·관측시간 수·마지막 양의 생산기록 이후 경과시간·직전날 07~16시와 전주 같은 시간 비교. 비가동 확정이 아닌 관측 컨텍스트다.
- B2: B1 + 최근 14일의 같은 15분 시각 전력 중앙값·분산·최소·최대·관측수, 같은 요일 반복값, 최근 대 전주 비율을 곱한 템플릿, 주간 패턴 변화. 완전히 끝난 과거 구간만 사용한다.
- B3: B2 + 기존 과거 생산·인원·날씨 특징, 생산 유무의 lag 일치도, 최근 생산/전력 변화 비율, 요일/업무시간과 최근 생산 상태 상호작용. 미래 날씨나 생산계획을 사용하지 않는다.

외부 상황(휴가·고장·주문·납기)은 직접 관측되지 않는다. 이름을 붙여 실제 원인으로 만들지 않고 가동 변화의 대리값만 검증한다. 기록 생산량 0은 휴가·정지의 확정 라벨이 아니다. 온도도 과거 관측값이며 미래 예보로 표현하지 않는다.

## 공정한 비교

4그룹×2구조=8개 회귀 후보와 전주 동일시각 기준을 동일 월/행에서 비교한다. 구조는 기존 LightGBM 설정과 두 단계 혼합: 과거 학습의 생산기록 양수 여부를 분류하는 gate + 기록 0/양수별 전력 회귀 2개, 최종값은 gate 확률로 가중평균한다. gate 확률은 미보정이며 실제 가동 확률로 주장하지 않는다. 상태 오분류까지 포함한 최종 전력값을 평가한다. 회귀기 설정은 고정하여 피처/구조 효과를 분리한다.

피크 전용 분류는 B0/B3에서 별도로 비교한다. 타깃은 해당 fold 학습 전력의 95백분위 이상 여부. PR-AUC(average precision), Brier, 고정 0.5 임계값의 F1/FN/FP를 공개한다. 회귀값을 고분위수로 바꿔 평균오차를 비교하는 방식은 이번 범위에 넣지 않는다.

## 시간 분할과 선택

4/5/6월 expanding folds로 후보를 비교하고, 평균 절대오차 최소의 2% 이내 후보 중 일최대 오차 최소로 선택(동률 이름순). 기준모델도 선택에 포함한다. 선택 파일을 기록한 다음 7월 29일에 고정 후보를 평가한다. 7월도 이전 연구에서 본 자료이므로 시간외 재평가이며 새 독립 시험이 아니다. 8~9월은 이번 실험에서 평가하지 않는다.

피크 분류는 회귀 후보 선택에 섞지 않고 보조 성능으로 공개한다. 향후 미탐/오경보 비용에 맞는 임계값·확률보정은 별도의 시간 분할이 필요하다. 피처가 늘어도 개선되지 않으면 그대로 보고한다.

## 누수 검사

각 과거 원천 구간 종료시각≤origin을 확인한다. target day 실제값은 학습 라벨/사후 평가에만 사용한다. 미래 시간대의 원시 전력·생산·인원을 변경했을 때 그 이전 origin의 신규 특징이 동일한지 검사한다. feature 목록과 그룹, fold별 결과를 보존한다.
