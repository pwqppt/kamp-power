# 데이터 한계에 따른 문제 재정의 v2 — 2026-10-06

상태: 기존 실험의 구조 재감사 + 문헌 대조 + 사전 관측조건별 탐색 진단 완료. 새 좁은 범위 모델 학습·확정·독립검증은 미실행. 성능이 좋은 사후 조건을 채택하는 문서가 아니다.

## 1. 데이터 스키마와 식별 가능 범위
- 원본: data/original.csv, 2021-01-01~09-14, 257일·6,168시간행·18열·24,672개15분값. 하루96값 완전 동일패턴142종, 반복그룹 소속160일. 142종은 독립표본142개라는 뜻이 아니다. 반복 원인이 실제 운전/복제/증강인지 불명확.
- 날짜·시간 + 15/30/45/60: 한 시간 내 4개 전력값. 시간은 시작시각, 15/30/45/60은 종료시각으로 가정. 평균은 4개값의 반올림 평균과 최대0.5차이. 같은 시간 평균으로 해당 시간의 미래4값을 예측하면 누수.
- 생산량·기온·풍속·습도·강수량·공장인원: 시간행에 결합된 기록. 실측/계획 구분·계측 위치/장치·수집/공개시각 미확인. 4구간에 반복해도 4개 새 관측이 되지 않음. 소수 인원3,510행 때문에 법적 인원수로 해석 불가.
- 전기요금(계절),인건비: 원자료 열. 인건비1/1.5는 사용자 시급13,000/16,000과 다름. 해당 열로 실제 비용/계약을 확정할 수 없음. day/d/m는 원자료 파생 달력이며 직접 타임스탬프에서 재생성.
- 어느 공장/설비/산업군인지, 동일 계측 범위인지, 전력 단위, 기상정보 출처, 작업별 가동/제품/교대/이동 가능 정보 미확인. 출제배경에 나온 조건이 모두 열에 있는 것은 아님.
- 결측: 풍속3·강수량1·인원17행. 전력/기온/습도/생산량의 명시적 NaN은 없음. 전력0은74구간, 생산0은2,657행; 결측이나 공장정지로 일괄 변환하지 않음.
- 시간 오류:7/13·7/15의48행. 행 순서 보정은 가정이며 해당 날짜 타깃 제외·과거 입력마스킹. 라벨노이즈율/센서오차율은 추정 불가. 갑작스런 정상 부하변화는 틀린 정답과 다름.

## 2. 시점·타깃·확률
정시 t에 종료<=t인 데이터만 입력. 업로드 지연0은 가정이며60분 지연민감도를 따로 평가.
- 연속값 타깃: Y_t=(y_{t+15},...,y_{t+120}). LightGBM L2는 조건부 평균을 근사하며 숫자 출력 자체가 확률은 아니다.
- 사건 타깃: Z_t=1{max(y_{t+45},...,y_{t+120})>c}. 현재 y_t<=c인 상황의 앞으로 새 고부하에 진입을 별도로 평가. 45분은 구간종료시각이므로 첫 대상 구간 시작은t+30분이며 준비30분과 맞춘다.
- p_t=P(Z_t=1|관측이력): 사건을 직접 학습해야 함. 6구간확률을 독립이라고 곱하면 안 됨. 확률의 Brier/신뢰도곡선/시간변화 검증 필요.
- 기존 c는 각 월 이전 전력95백분위로4/5/6/7월178/176/175/176. 고부하 상대 기준이며 계약·물리적 위험한도가 아니다. 월별 사건 성능에 기준변화 영향이 섞임. 새 case에서는 개발기간에서 c를 고정한 비교를 추가할 것. 계약한도는 추후 실제 입력으로만 대체.

## 4. 이번 재점검의 핵심 인사이트
1. 쉬운 비생산/저부하만 남기면 MAE는 낮아도 피크결정의 가치가 사라짐. 사건수·적용률·제외된피크를 같이 보고할 것.
2. 현재 이미고부하인 상황의 지속탐지는 재현율을 높여도30분준비의 새작업판단에는 늦을 수 있음. 발행당시 아직고부하가 아니고 준비시간 이후에 진입하는 사건이 핵심.
3. 작업시점 선택에는 값의오차뿐 아니라 후보시점의 상대순서·최대총부하·판단차이가 중요. 공통편향은 후보순서를 보존할 수 있고, 작은 오차도 가까운 후보의 순서를 바꿀 수 있음. 따라서 MAE와결정손실을 별도측정.
4. max(E[Y|X])와E[max(Y)|X]는 다름. 평균값모델을잘맞춰도 미래최대/초과확률은 과소추정 가능. 별도최대/사건타깃이 필요.
5. 정보가 없어서 작은문제로좁히는 것과 쉽게맞는정답을고르는 것은 다름. 기록상조건을 발행때 판정하고 포함/제외성능을 모두 보존할 것.
6. 학습일반복을없애면 학습량/계절분포도 달라짐. 반복제거7월MAE8.107→9.536은 민감도증거이지 반복만이 성능을부풀린인과증명이 아님.

## 5. 분야명 없이 쓴 통계 구조
X_t=발행시점까지 기록, S_t=미관측상태, Y_t=6개 미래관측벡터. 관측기록 W_t=h(S_t)+측정오차일 수 있으나 이 자료에서 오류분해 식별불가.
예측: f(X_t)≈E[Y_t|X_t], p(X_t)≈P(maxY_t>c|X_t).
적용선별: g(X_t)∈{0,1}; coverage=P(g=1), conditional risk=E[L(Y,f(X))|g=1]. 제외된(g=0) 구간의 성능/사건수도 보고.
결정: a∈{시작지연0,30,60분}; C(Y,a)=max_h(Y_h+J_h(a))+λ·지연(a). λ는 알려진비용이 아니라 민감도가정.
실제값평가: regret=C(Y,a_hat)-min_a C(Y,a). 결정효과는 C(Y,a즉시)-C(Y,a_hat)와 별개로 같이보고. oracle는참고상한이며운영입력으로사용불가.
반사실 가정: Y^a=Y+J(a). 배경작업이 반응하지 않고 가상작업이 단순가산된다는 강한가정. 관측자료만으로 실제 생산/요금의 인과효과를 식별할수없음.

## 7. 새 case 후보와 직접 실행한 탐색 진단
범위 후보: 최근2시간전력8개모두관측, 최근생산량기록>0, 현재전력∈[과거전력q75,과거q95]. 현재이미고부하가 아닌 작업시작판단상황. 통계분위수는 물리적공정상태가 아님.
45~120분만 평가(전체15~120 결과도보존). 코드 scope_audit.py, outputs/scope_audit.
7월: 98/693발행=14.1% 적용, 전체새고부하99건 중52건=52.5% 포함. 이범위의 LightGBM MAE11.621 vs전주13.281; 최대값MAE12.844 vs전주11.592, 회귀값기준사건재현율32.7% vs전주73.1%.
즉 범위선택으로만 기존피크실패가해결되지는 않음. 저오차제시가 아닌 집중된결정상황이라는 논리로후속후보. 이자료를보고 만든정의이므로탐색이며새독립검증필요. 좁은case성과가확보됐다는선언금지.
권장문제정의: '최근관측이충분하고현재부하가높아지는여지가있는기록상생산구간에서, 준비30분인추가작업을시작하거나최대60분늦추기위해향후45~120분전력·고부하진입위험을예측한다.' 현재부하가실제상승중이라고선별한것은아니므로표현시현재높은편이라는의미로한정.
선택포기: 범용공장·연간계절일반화·가동/냉방인과설명·실제생산보존·실제원화절감보장. 유지: 전체예측/피크진단 및 case적용률/제외영역실패,조건부운영효과.
