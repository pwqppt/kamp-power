# 확정 조건과 가정

| 항목 | 결정 | 성격 |
|---|---|---|
| 예측 시점 | D-1 16:00, D일 96구간 | 실험 설계 |
| 시간축 | 시간=시작시간, 15/30/45/60=구간 끝; 60분은 다음 시각 | 메타정보 미확인 가정 |
| 전력 단위 | 통계는 원자료 단위. 요금은 kW 확인 또는 명시적 kW 가정 필요 | 미확인 |
| 예측 모델 | F2 + LGB_medium, seed42 | 검증 기반 1차 고정 |
| 비교 | SeasonalNaive 유지; oracle 별도 | 고정 |
| 결측 | LightGBM 자체 결측 분기, 선형/트리 일부는 학습자료 중앙값 대체 | 구현 확인은 experiment.py |
| 극단 전력 | 정상 피크일 수 있어 기본 실험은 보존 | 고정 |
| 부하 이동 | 0/5/10/15%, 앞뒤 30/60분 | 구현 예정인 가정 시나리오 |
| 노동비 | 시급 13,000/16,000원. 인원·추가 노동시간 별도 | 사용자 지정 시나리오 |
| 운영 성과 | 미조정·단순 예측·AI·완전예측 참고를 동일 제어 조건에서 비교 | 구현 예정 |
| 요금 | 계약종별·계약전력·역사 최대수요·시행일 분리 | 미확인/구현 예정 |
| 연구 비중 | 예측·요인·피크저감 80~85%, 정책·경제성 15~20% | 고정 원칙 |
| 외부자료 | 모델에는 미사용, 비용 후처리·시나리오에만 사용하고 대장 기록 | 고정 원칙 |

새 정책이나 모델을 테스트 결과를 본 뒤 선택하면 ‘최종 검증’이 아니라 후속 탐색으로 표시한다. test 성능이 좋은 전처리를 기존 실험에 소급 적용하지 않는다. 특징 중요도·조건별 오류는 인과관계 증명이 아니다.
