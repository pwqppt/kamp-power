# 피크 개선 실험: 세 가설과 중단 규칙

2026-10-02. 출발 커밋 `04e0f29b08f4582ddf4635547355c5f9f8db3c7e`.
이 파일은 새 후보의 성능을 계산하기 전에 고정한다. 7월은 이미 알려진 사후 진단 구간이며 독립 테스트가 아니다.

## 실행 순서와 범위

1. 저장된 결합모델의 7월 출력을 기온·생산기록·시간대로 분해한다. 일최대 크기, 실제 최대시각에서의 오차, 최대시각 차이를 구분한다.
2. 아래 세 가설을 각각 한 번만 실행한다. 트리 크기·반복횟수·학습률·상태 결합 임계값 0.5는 기존 설정을 유지한다. 가중치나 보정 상한을 7월 결과로 변경하지 않는다.
3. 평균전력 예측 → 오차 집중조건 → 피크 발생조건 → 피크 저감 시뮬레이션 순으로 결과를 정리한다. 경제성은 이번 실행에 포함하지 않는다.

## 고정 가설

| ID | 방법 | 한 번만 실행하는 설정 | 실패 가능성 |
|---|---|---|---|
| H1 | 피크 가중학습 | 학습 전력의 95백분위 이상 행에 가중치 2, 나머지 1. 두 상태 회귀기에 적용. 상태 분류기와 0.5 결합은 유지 | 평균오차·과대예측 증가 |
| H2 | 피크 과소예측 비대칭 제곱손실 | 학습 타깃이 학습 95백분위 이상이고 과소예측이면 제곱손실 계수 2, 그 외 1. H1과 결합하지 않음 | 과대예측 증가, 희소한 피크에 민감 |
| H3 | 과거 시계열 OOF 잔차 보정 | 3월부터 예측한 과거 월의 기준모델 OOF 잔차만 사용. 예측값이 해당 학습 90백분위 이상인 구간의 평균 잔차를 0.5배 축소하고 [0, 현재 학습 95백분위의 10%]로 제한. 같은 위험구간에만 더함. 과거 위험구간이 96개 미만 또는 7일 미만이면 보정 0 | 계절 변화에 부적합, 평균오차 또는 오경보 증가 |

H3의 보정 자료는 각 외부 fold 첫 예측시점 전에 전체 하루 실측이 끝난 날만 허용한다. 4월은 3월 OOF, 5월은 3~4월, 6월은 3~5월, 7월은 3~6월을 사용하되 각 시작일 전날은 제외한다. 보정값은 해당 평가 월 중 갱신하지 않는다.

## 예측시점과 누수 방지

- D-1 16:00까지 구간이 끝난 과거 데이터만 사용한다. 지연 0 가정은 현장 확인 대상이다.
- 실제 미래 기온·생산량·인원은 학습이 끝난 예측기의 입력에서 제외한다. 과거 학습 라벨과 사후 분석에만 허용한다.
- B1 컨텍스트 열을 그대로 사용한다. 기온 예보를 확보한 것으로 표현하지 않는다.
- 학습은 fold 시작 이전 완결된 96구간 날짜만 허용한다. 7/13·7/15 제외와 해당 과거전력 결측 처리는 유지한다.
- 입력 열 허용목록, 학습/보정 라벨 종료시각 검사, 미래 원자료 교란에 대한 특징 불변 검사를 실행한다.
- 8~9월 재평가·재선택 없음. 알려진 4~7월을 재사용하므로 채택되어도 탐색 후보이며 독립 검증이 필요하다.

## 평가와 채택

실행 전 재현 점검 추가: 과거 저장값은 현 Windows/Python 3.13 환경에서 완전히 같지 않지만, 원래 함수와 새 비교 함수는 같은 환경에서 출력이 정확히 같다. `historical_drift.csv`와 `reproduction.json`을 공개하며 모든 후보를 현재 환경 원래 함수의 대조군과 비교한다. 성능을 맞추기 위한 하이퍼파라미터 변경은 하지 않는다. Windows에서는 모든 Python 명령에 `-X utf8`을 사용한다.

4·5·6월 expanding rolling time validation의 동일 91일·8,736구간에서 기존 결합모델(`predicted_state_0.5`)을 대조군으로 둔다. 전주 동일시각 기준도 함께 공개한다.

새 후보는 **다음 조건을 모두 만족할 때만** 다음 탐색의 후보로 채택한다.

1. 합산 평균 MAE가 기존 결합모델 이하(부동소수점 허용 1e-9).
2. 합산 일최대 MAE가 기존 결합모델보다 감소.
3. 피크일 재현율이 증가하고 구간 피크 재현율은 감소하지 않음.

피크는 각 fold 학습 전력의 95백분위 이상으로 고정한다. 월별 점수와 TP/FN/FP/TN·정밀도·F1도 모두 저장한다. 조건을 통과한 후보가 여럿이면 일최대 MAE, 평균 MAE, ID 순으로 선택한다. 통과자가 없으면 기준 결합모델을 유지하고 추가 탐색하지 않는다.

7월 출력은 4~6월 판정을 JSON으로 저장한 뒤 계산한다. 7월 우세를 이유로 탈락자를 승격하거나 설정을 바꾸지 않는다. 일 단위 paired bootstrap 2,000회(seed 42)의 MAE·일최대 MAE 차이 구간은 기술적 불확실성으로 표시하며 독립 관측의 유의성 주장에 사용하지 않는다.

## 운영 실험

채택 판정을 마친 후 유지/선택 모델과 전주 기준, 무조정, oracle 참고를 동일 제약에서 비교한다. 기존 정의를 유지한 0/5/10/15% 비율 이동, ±30/60분 시나리오를 전부 보고한다. 후보/비율/시간창을 7월 저감 실적으로 다시 고르지 않는다. 예측으로 고정한 이동행렬에 실측을 적용하고 일별 악화·전체기간 최대값·이동량·보존오차를 기록한다. oracle는 실측을 알고 계획하는 별도 참고다. 설비 실행 가능성·생산량 보존·금전 절감은 입증되지 않는다.
