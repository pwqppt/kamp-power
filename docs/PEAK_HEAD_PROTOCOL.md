# 추가 요청에 따른 H6: 평균곡선과 일최대 예측의 목표 분리

2026-10-02, 실행 전 기록. 사용자는 5개 가설의 실패 결론으로 보고서를 확정하지 말고 개선 방법을 더 깊게 찾으라고 추가 지시했다. 최초 5개 비교는 종료·보존하고, 범위를 **추가 구조 가설 1개**로 한정한다. 무한 탐색은 하지 않는다.

## 왜 별도 목표인가

각 15분의 조건부 평균을 예측한 뒤 그 최대값을 취하면, 일반적으로 ‘하루 최대값의 조건부 기대값’과 같지 않다. 피크 발생 시각의 불확실성만으로도 평균 곡선의 최고점이 낮아질 수 있다. 구간 손실의 비대칭화와 고온 일괄 보정으로 해결되지 않은 원인이 될 수 있다. 실제 원인 전체를 입증했다는 주장은 하지 않는다.

## 고정 설계

- 15분 전력 예측은 현재 기준 `reference`를 그대로 사용한다. H4를 사후 선택하지 않는다.
- 일최대 예측을 별도 출력으로 제공한다. 예측치 = 0.5 × 기존 결합 곡선의 최대 + 0.5 × 전주 기준 곡선의 최대. 서로 다른 실패 양상을 갖는 두 추정량의 고정 동일가중 결합이다. 0.5는 최적값 탐색으로 선택하지 않는다.
- 어떤 실제 미래 최대값·기온·생산량도 입력하지 않는다. 일최대 임계값은 기존 훈련95분위수. 일최대 예측은 96구간 곡선의 최대와 같다고 주장하지 않는다. 실제 부하이동 계획은 96구간 곡선만으로 계산한다.
- 4~6월 91일에 한 번 검증한다. 구간 MAE는 동일해야 하며 일최대 MAE 감소·피크일 재현율 증가·일최대 과소예측 비증가를 모두 요구한다. 구간 피크 재현율은 그대로다. 이는 새 96구간 모델의 채택이 아닌 **보조 일최대 예측 출력**의 채택이다.
- 전주 기준 대비 일최대 MAE/재현율도 반드시 함께 공개한다. 모든 지표에서 기준 우위라고 쓰지 않는다. 판정 저장 뒤 7월은 한 번 사후 진단만 한다.
- paired day bootstrap 2,000회 seed42, 월별 성능, FP/FN/F1을 보존한다. 과거 검증 재사용 때문에 독립 검증이 아니다.
- 개선이 있으면 보고서는 평균전력 예측의 실증적 이득과 보조 일최대 출력의 확인된 기여를 중심으로 작성한다. 이전 실패는 선택 근거를 위한 간결한 부록으로 남긴다. 성과가 확인되지 않으면 숫자를 숨기거나 성공으로 표현하지 않는다.
