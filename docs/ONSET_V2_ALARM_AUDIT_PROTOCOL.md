# 고부하 진입 v2 경보 기준 민감도 사전 계획
기존 모델 및 정답 정의를 바꾸지 않고 경보 기준과 단순 비교 모델을 검증한다.

- 고정: LightGBM F0, 현재 정상 → 향후 15~120분 첫 고부하 진입; 준비시간 요구 없음.
- 비교: 전주 최대, 전일 최대, 현재 전력값만. 동일 보정과 동일 평가 행.
- 사전 고정 경보 목표: 과거 정상 오경보율 1%, 2.5%, 5%, 10%. 과거 음성 점수의 상위 분위수, 초과(>) 판정.
- 과거 보정: 기존 월별 분리된 14일+14일 구간과 엄격한 미래 정답 경계 유지.
- 4~6월/7월 및 월별 TP·FP·FN·TN/재현율/정밀도/실제 오경보율/AP 보고. 7월은 자료 재사용 진단.
- 기존 확률과 5% 경보 완전 재현, 후보 행 일치, 기준 보정 정답의 시간 경계 검사를 완료 기준으로 한다.
- 실제 오경보율을 같게 맞추는 ROC 결과는 사후 진단으로 분리한다. 평가 정답으로 배포 임계값을 고르지 않는다.
- 실패 조건: 기준까지 남은 비율10% 안/밖, 최근15분 전력 상승/비상승, 관측 생산량0/>0, 관측기온30초과. 표본 수/양성 수와 작은 표본 표시. 진단 조건은 성공 범위나 모델 입력으로 재선택하지 않는다.
- 현재 이 단계에서는 운영 기준을 확정하지 않고 원화 절감/물리적 설비 이동을 주장하지 않는다.
- 각 목표에서 두 모델의 재현율/오경보율 차이를 일별 7일 블록 bootstrap으로 진단한다. 반복 곡선 편향을 해결했다는 의미는 없다.

- 실행: python onset_v2.py → python onset_v2_alarm_audit.py.
