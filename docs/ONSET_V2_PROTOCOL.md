# 고부하 진입 예측 v2 — 준비시간 조건 삭제 (2026-10-07)

## 사용자 수정사항
30분은 실제 설비에서 확인한 준비시간이 아니라 연구 가정이었다. 따라서 이전의 '실제 준비시간을 확보하지 못했다'는 표현은 철회한다. 설비 정보가 없으므로 이번 예측 문제에서 준비시간/작업 이동 가능 여부를 고려하지 않는다.

## 목표와 정답
- 현재 관측 전력이 고부하 기준 이하인 정시에서 향후 2시간 내 처음 고부하가 되는지 예측한다.
- 미래 15/30/45/60/75/90/105/120분 구간 끝시각 중 하나라도 처음 초과하면 정답1. 모두 기준 이하면0.
- 15분/30분 뒤 진입도 정상 양성이다. '너무 빠르다'며 오경보로 처리하거나 평가 대상에서 제외하지 않는다.
- 현재 이미 고부하인 시점은 새 진입 문제의 적용 대상이 아니며 제외 수를 함께 보고한다. 미래 8값이 모두 관측되는 경우만 타깃을 평가한다.
- 고부하 기준은 각 월 시작 이전 전력 q95로 고정한다. 이것은 데이터상 기준이며 실제 설비 위험·계약전력으로 해석하지 않는다.
- 매정시 갱신은 기존 실험 조건으로 유지한다. 실제 에피소드 전체 대비 적용/탐지 범위는 보고하되, 어떤 설비를 몇분 안에 옮겨야 한다는 성공 조건은 없다.

## 공정한 비교
- onset_v2.py는 이전 모델을 별도 경로 outputs/onset_v2에서 재학습한다. 정답 변경에 맞춰 학습·확률보정·경보임계값과 전주/전일 기준도 모두 다시 계산한다.
- 전주/전일 기준은 미래에 대응하는 과거8구간 전체 최대를 사용한다. 초반15/30분의 예측초과를 억제하는 규칙도 삭제한다.
- F0/F1 동일파라미터 비교,4~6월 AP 기반 선택을 고정한 뒤7월 재사용 진단. 미래 실제 생산·기온·인원 입력 금지.
- 첫14일 확률보정/뒤14일 경보보정이라는 이전28일 분리 구조 유지. 경보 목표오경보5%는 과거보정의 목표이지 미래 보장이 아니다.
- 재현율·정밀도·FPR·AP·Brier·실제 사건별 탐지·적용범위·조건별 실패를 함께 보고한다. 재현율만 높이는 임계값 선택은 하지 않는다.
- 기존 82.0%/12.9% 등은 준비시간 조건이 있던 다른 타깃의 결과다. 새 타깃 성능으로 인용하거나 숫자만 재분류해 모델 개선이라 하지 않는다.
- 끝시각에 대한 첫진입 위치를 남길 수 있지만 시간 정보는 설명용이며 준비시간 필터/경제성 성공 조건으로 사용하지 않는다.
