# 주간 기준 잔차 보정 가설

2026-10-02 사용자 후속 요청. B1_mixture는 7월 양의 생산기록 구간에서 MAE 13.478로 기준 16.281보다 작지만, 생산 0 구간에서는 22.375로 기준 5.080보다 크다. 이는 사후 조건별 관측이며 미래 실제 생산량으로 두 모델을 선택할 수 있다는 뜻이 아니다.

이번 가설은 ‘전주 같은 시각 값을 기본값으로 유지하고 과거 컨텍스트를 이용해 예상되는 차이만 회귀하면 불필요한 보정을 줄일 수 있다’이다. 타깃은 실제 전력−예측 시점에 이미 알려진 주간 기준값. 최종값은 max(0, 기준값+alpha×예측잔차).

사전 후보: 피처 B1/B3 × 고정 LGB_medium/LGB_smooth × alpha 0.25/0.5/1 = 12개. alpha 0인 무보정 기준도 포함한다. 4/5/6월만으로 MAE 최소의 2% 이내에서 일최대 오차 최소를 선택, 동률 MAE·이름순. 선택 JSON 기록 뒤 7월을 평가하며 그 결과로 재선택하지 않는다. 8~9월은 평가하지 않는다.

기존 v2 선택은 그대로 보존한다. 새 가설은 기존 7월 결과를 보고 만들어졌으므로 7월 성능은 더더욱 탐색 재평가이며 새로운 독립 검증으로 주장하지 않는다. 현업 의미는 반복 패턴의 유지와 변화 감지지만 인과효과나 실제 설비상태 관측으로 표현하지 않는다. 기준모델이 강한 원인 분석은 생산상태·주간 전력 일치·학습내 일패턴 반복을 함께 확인한다. 중복 패턴 존재만으로 증강이나 누수를 확정하지 않는다.
