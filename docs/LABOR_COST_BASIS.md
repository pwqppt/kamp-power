# 노동비 차액 산정 기준 — 부분 체크포인트

확인일: 2026-10-02 (한국시간). 이번 범위는 인건비 정의와 시나리오 고정이며, 한전 요금 확인·경제성 시뮬레이션은 미완료다.

과거 상담은 적용범위 참고자료다. 실제 대상 사업장 해당 여부, 계약상 더 높은 가산율, 통상임금 구성과 근무 허용 조건은 확인되지 않았다. 이번 연구의 주 시나리오는 제56조가 적용되는 성인 근로자의 평일 근무를 가정하며, 법적 적용 예외가 없는 것으로 둔다. 실제 급여 정산용 도구가 아니다.

## 우리 연구에 적용할 계산 원칙

다음은 법률의 직접 문구가 아니라 연구상 비용 비교 설계다.

**추가 노동비 = 변경 후 지급해야 하는 노동비 − 기존 일정의 노동비.**

전력 부하 이동 시간과 근로자 근무 증가 시간을 동일시하지 않는다. 단순 부하 이동만으로 인건비가 자동 증가하지 않으며, 야간 전력을 사용했다고 직원 전체에 추가 수당을 부과하지 않는다. 두 일정에서 실제로 필요한 작업 인원·시간을 따로 둔다.

시급 13,000/16,000원은 사용자가 지정한 비교값이며, 여기서는 ‘시간당 통상임금’이라고 추가 가정한다. 실제 공장 시급을 확인한 결과가 아니다. 데이터 인건비 열의 1/1.5를 법정 배율이나 원화 임금으로 사용하지 않는다.

## 평일 1인·1시간의 예시

| 경우 | 비용 차이 계산 | 시급 13,000원 | 시급 16,000원 |
|---|---|---:|---:|
| 이미 배치된 인력으로 처리, 유급시간·야간/연장시간 불변 | 차이 없음 | 0원 | 0원 |
| 주간의 기존 1시간을 야간으로 대체, 총시간 동일·연장 없음 | 기본급 상쇄, 야간 가산 0.5×시급만 증가 | 6,500원 | 8,000원 |
| 야간 일반근무 1시간 순증, 연장 아님 | 기본급 1.0 + 야간 가산 0.5 | 19,500원 | 24,000원 |
| 야간 연장근무 1시간 순증 | 기본급 1.0 + 연장 가산 0.5 + 야간 가산 0.5 | 26,000원 | 32,000원 |

추가시간이 법적 연장근로인지 여부는 직원별 기존 일·주 근로시간과 계약을 알아야 판단할 수 있다. 표의 사례는 해당 분류가 이미 확인됐다고 가정한 산술 예시이며 자동 근무 분류가 아니다. 휴일과 단시간근로자 등은 별도 규칙 확인 전 이번 예시에 넣지 않는다.

30분 이동이라도 새로 야간이 된 근무가 15분뿐이면 15분만 가산한다. 예: 기존 21:30~22:00을 21:45~22:15로 대체하면 야간 증가 0.25시간이다. 기본급 상쇄·연장 없음 가정에서 1인 추가비는 1,625원 / 2,000원이다. 이동이 하루를 넘으면 날짜별·직원별 근무기록 확인이 필요하다.

## 향후 시뮬레이션 입력

- 주 시나리오: 기존 인력으로 처리 가능한지 확인되지 않았으므로 ‘추가 노동비 0’은 조건부 시나리오로만 둔다.
- 민감도 축: 영향 인원 1/2/4명, 근로자당 추가/전환 시간 0.25/0.5/1시간. 측정값 또는 대표 공장값이 아닌 스트레스 테스트 범위다.
- 같은 이동으로 여러 구간을 조정할 때 근무시간을 중복 합산하지 않는다. 직원별 추가 근무 구간의 합집합을 산출한다.
- 추가 인원은 공장 전체 인원과 다르며 데이터의 소수 인원을 그대로 곱하지 않는다.
- 사회보험 사업주 부담, 교통·식대·채용·인수인계·설비 재기동·AI 운영비는 미확인이다. 제외했다면 ‘노동비 일부만 반영한 순이익’으로 표시하고 총순이익으로 주장하지 않는다.
- 노동비만 회수하는 손익분기 전기요금 절감액은 해당 추가 노동비와 같다. 실제 절감액은 아직 계산하지 않았다.
- 시간제 요금의 저렴한 구간과 법적 야간근로 구간은 별도 시간표로 관리한다.

## 다음 한 작업

한전 공식 현행 요금표·공급약관의 시행일, 계약종별, 요금적용전력의 적용월·하한·측정 시간대를 확인해 출처표를 작성한다. 단위와 계약이 확인되지 않으면 가정으로 남긴다. 전력요금 수치 확정 전 통합 경제성 모델은 시작하지 않는다.
