# 예측 상태별 기준 유지 탐색

2026-10-02, 실험 실행 전 후보 고정. 기존 B1_mixture의 생산기록 양수 확률(과거 정보로 예측)이 0.5/0.75/0.9 이상이면 혼합 회귀값을 사용하고 아니면 주간 기준값을 유지한다. 항상 혼합·항상 기준을 포함하여 5개 후보를 4/5/6월에서 비교한다. 평균 MAE 최소의 2% 이내 후보 중 일최대 오차 최소를 선택하고 7월 고정 재평가. 7월 수치로 재선택하지 않는다. 기존 테스트는 사용하지 않는다.

이 가설은 이미 본 7월의 실제 생산상태별 성능 차이에 착안한 사후 탐색이며 새 독립 검증이 아니다. 추론 조건은 예측 상태 확률뿐이고 실제 미래 생산량은 사용하지 않는다. 확률은 미보정이므로 실제 가동 확률로 부르지 않는다. 후보군을 결과에 맞춰 추가하지 않는다.
