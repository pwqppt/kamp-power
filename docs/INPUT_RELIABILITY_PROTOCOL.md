# 입력의 예측 기여 검증: 사전 실험계획 (2026-10-06)

목적은 열의 물리적 진실성을 확정하는 것이 아니라 **이 자료/시점/모델에서 어떤 입력이 예측에 도움이 되는지** 검증하는 것이다. 원본 복제나 부가정보 연계 오류를 결과만으로 확정하지 않는다. 중복 제거/가중치 조정은 이번 주 실험의 해결책으로 사용하지 않는다.

## 통제
- intraday.py의 시간 계약 유지: 매정시, 향후15~120분 8구간. 보조 평가45~120분은 준비30분 이후 구간(끝시각45분부터).
- 입력은 발행시점까지의 전력과 완료된 시간별 생산/기온/습도/인원 기록. 실제 미래값 금지. 계측/입수 지연0 가정은 미확인.
- 원본 해시, 시간오류 제외, 원본 결측/피크 보존. LightGBM 기본 결측 분기 사용. 입력 추가 시 행을 더 제외하지 않는다.
- 동일 LightGBM 회귀/분류 파라미터(seed42), 월시작 타깃 차단 expanding 학습,4/5/6월 검증,7월은 재사용 진단.
- 9집합: 최근전력+달력, +전일/전주(F0), +최근통계(F1), F1+생산량, F1+기온, F1+습도, F1+기온/습도, F1+인원, F1+4종전체. 외부정보 특징은 값/시간별변화/결측/최근관측나이의 동일블록. 풍속/강수량은 이번범위 제외.
- 블록 추가의 주 비교는 F1 대비. F0 대비도 별도 기재. 특징중요도만으로 믿을 열을 선택하지 않는다.

## 평가/선택
- 회귀 MAE,RMSE,과소예측편향,2h최대MAE,고부하 회귀재현율/FPR.
- 직접 구간 분류: 회귀와 분리,학습 마지막28일은 임계값 보정용으로 남기고 이전자료만 fit;월학습자료 전력q95를 고부하 정의로 고정. 보정 정상구간의 점수95백분위보다 큰 경우 경보,재학습 없음. 15~120 및45~120 범위 각각 보정. 임계값 조정은 확률 자체의 보정이 아니다.
- 직접분류 AP/Brier/재현율/정밀도/FPR. 준비구간 경보는 개별구간 성능으로 표시하며 실제 사건/창 경보로 부르지 않는다.
- 회귀 선택:4~6월 풀링MAE 최저의1% 이내 후보 중 특징수가 최소인 집합. 분류는4~6월 풀링AP 최저가 아닌 **최고**의1% 이내(>=0.99*max) 후보 중 최소특징 선택;FPR과재현율 별도로보고. 이규칙은7월 전에적용하며두목표의결론이달라도강제결합안함.
- paired 날짜오차와7일블록 bootstrap(2000회),추가특징의개선이3개월일관적인지보고. 이신뢰구간은이미살펴본자료재사용/모델선택의낙관성을해결하지않음.
- 반복/비반복,학습곡선동일/새곡선은 전체미래실측을쓰는사후진단. 실시간입력/모델분기/좋은case선택으로사용금지. 부하/월/표본수차이로인과효과를추론하지않음.
- 부가정보값이60분오래됐지만지연표시없이수신되는상황(관측나이는도착시각기준) 및20%시점누락은 외부정보만 변형한 회귀감도. 전력이력/정답은보존, 학습재조정없음. 민감도가작아도열이물리적으로옳다는뜻아님.

출력은별도 outputs/input_reliability_v1. 모든후보7월평가는사후진단임을표시하며7월로선택변경안함. 새논문/외부자료사용없음. 본단계에서수익/실제공정최적화의인과효과를계산하지않음.
