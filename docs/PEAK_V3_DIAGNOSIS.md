# 7월 피크 과소예측 진단

2026-10-02. 기존 `adaptive_v2/selected_july.csv`를 그대로 분석한 사후 진단이다. 7/13·7/15를 제외한 29일, 2,784구간. 임계값은 7월 첫 예측 이전 학습 전력의 95백분위 176(원자료 단위).

## 기온

과거 학습 기온 3분위 경계 10.5/17.2도에 비해 7월 관측값은 전부 최상위 구간에 있다. 이 분류로 7월 내부의 기온 효과를 구분할 수 없어 고정 5도 간격의 사후 기술통계도 병기한다. 모델 설정이나 채택에는 쓰지 않는다.

더운 구간에 큰 과소예측이 동반된다. 그러나 온도·생산·시간·날짜가 함께 바뀌며 비교 가능한 통제자료가 없으므로 냉방의 인과효과로 해석하지 않는다. 시간별 기온과 생산기록이 15분 네 구간에 반복되므로 표본 구간 수는 독립 관측 수가 아니다. 모든 기온×생산상태×시간대 조합은 조건 CSV에 공개했다.

## 피크 크기와 시각

일최대 MAE 20.594, 일최대의 평균 편향 -12.943. 실제 최대시각에서의 평균 편향은 -21.171로 더 크다. 첫 최대값 시각을 사용하는 절대 시각오차 평균은 168.6분이며 동률·넓은 고원형 부하에서는 해석에 주의한다.

## 재현성 점검과 이번 비교 기준

고정 라이브러리 버전을 설치했으나 과거 Python 3.12.14 실행과 현재 Windows/Python 3.13 실행의 저장값은 완전히 같지 않다. 새 비교 함수와 원래 `context_features.predict`는 현재 환경에서 출력이 정확히 일치한다. 특정 차이 원인은 아직 확정하지 않았다.

현재 원래 결합모델의 4~6월 평균 MAE 16.910845, 일최대 MAE 19.992784, 피크일 재현율 29.545%; 7월 평균 MAE 10.552418, 일최대 MAE 20.438270, 피크일 재현율 70%. 새 가설은 이 동일 환경 대조군과 비교한다. 과거 결과를 덮어쓰지 않는다. 월별 차이는 `historical_drift.csv`, 환경은 `reproduction.json`에 기록했다.

6/15·7/20 예측시점 이후 원자료 전력·기온·생산·인원·기타 날씨를 999999로 바꾸고 특징을 재계산해 B1의 모든 입력 불변을 확인했다. 미래 OOF 라벨을 바꾸어도 4~7월 보정값은 불변이다. 이것은 해당 경계·날짜의 회귀 검사이며 데이터 입수 지연 가정을 입증하지 않는다.
