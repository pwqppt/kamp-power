# 04 경제성 분석: 다음 작업의 범위와 완료 기준

## 먼저 확보할 근거
1. CSV의 전력 단위(kW인지 15분 kWh인지), 공장/계측 범위, 생산량 열의 의미. 모르면 가정으로 유지한다.
2. 한전 공식 공급약관과 선택 계약종별 요금표의 시행일. 2026 현행을 확인하지 못하면 2025 기준가격 시나리오로만 제시한다.
3. 요금적용전력: ‘직전12개월 전체 최대’라고 단순화하지 말고 적용 대상 월·현재 월·계약전력 하한·계측 시간대·예외를 확인한다.
4. 야간·연장·휴일 가산과 사업장 적용 조건. 시급 13,000/16,000원은 고정하고 인원·추가시간은 별도 축으로 둔다. 근무시간 이동의 추가 가산과 새 노동시간의 기본급을 구분한다.

## 검색 출발점 — 아직 구현에 사용할 검증 완료 원문이 아님
- 한전 공식 포털의 현행 전기공급약관, 산업용 요금표. 구 cyber.kepco 페이지는 접속 실패가 있었음.
- 한국물가협회 재게시 `https://data.cmpi.or.kr/program/board/2025.04.01%20%EC%8B%9C%ED%96%89.pdf` (2025-04-01 표, 공식 현행 원문 대체 불가).
- 국가법령정보센터 근로기준법 제56조, 최저임금위원회 2026 최저임금. 인용 시 시행일 재확인.
- 사용자 대회 공지: https://www.kamp-ai.kr/contestNoticeDetail?CPT_NOTICE_SEQ=29

## 구현 순서
- 요금/가정 JSON을 먼저 작성한다. 가정과 실측을 별도 필드로 둔다.
- 한 달 전체가 있는 2021년 8월을 우선 대상으로 한다. 9월 일부를 한 달 또는 연간 절감으로 환산하지 않는다.
- 0/5/10/15% 유연부하, ±30/60분 시나리오. 설비별 가능 여부는 확인되지 않았음을 명시한다.
- 예측값만으로 이동안을 만든다. 평가 실제값을 보고 이동을 다시 최적화하지 않는다.
- 원래 구간에서 뺀 에너지를 수신 구간에 더하고 전일 총량·비음수·이동 범위를 검증한다. 실제 가용 부하가 부족할 때는 불가능률을 기록하거나 사전에 정의한 실시간 제한 로직을 쓴다.
- 기준 무조정 / SeasonalNaive / 고정 AI를 같은 조정기로 비교한다. 실제값을 아는 완전예측은 도달 가능 참고 상한으로 분리한다.
- 역사 최대수요에 묶이면 기본요금 절감 0을 허용한다. 과거12개월 전체가 없어 초기 이력의 민감도를 별도 시나리오로 둔다.
- 에너지요금 차액 + 기본요금 차액 - 추가 노동비 - 운영/AI 비용으로 순이익과 손익분기점을 계산한다. 미확인 세금·부가항목은 포함/제외를 표기한다.
- 30~60분 이동을 밤샘 근무 전환처럼 해석하지 않는다. 추가 야간인력이 실제 필요한 경우의 손익분기점은 별도 노동비 시나리오로 제시한다.

## 완료 기준
실행 코드, 출처/시행일 표, 가정 JSON, 이동 보존 검증, 시나리오 결과 CSV, 비용 구성 그림, 손익분기점 그림, 무이득/손실 조건 요약이 모두 있어야 04 완료로 표시한다. 결과가 손실이면 그 조건에서 ‘조정하지 않음’이 결론일 수 있다.
