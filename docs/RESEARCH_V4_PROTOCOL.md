# 공식 요구 보완 실험: 실행 전 고정 설계

2026-10-02, `experiments/official-report-v4`. 피크 가설 H1~H3와 0/5/10/15%·30/60분 이동 실험을 종료한 뒤 작성했다. 모델·일정 정책은 기존 결합 유지 / 자동 일정 변경 미채택으로 고정한다.

1. 데이터 재확인: 공식 ZIP CSV와 원자료 바이트 해시 비교, 시간·결측·반복 및 교차 폴드 패턴 중복 기록. 반복 패턴을 본 뒤 유리한 표본만 고르지 않는다.
2. 비교 보완: 기존 설정의 Ridge(F2), ExtraTrees(F2), LGB_medium(F0/F1/F2/F3/B1 단일), B1 확률혼합을 4/5/6월 동일 expanding split에서 1회 실행. 가설은 ‘과거 전력·생산 문맥·상태 혼합의 각 기여를 구분할 수 있다’이다. 기존 결합과 전주 기준도 같은 행에 비교한다. 탐색을 재개하거나 이 결과로 고정 모델을 바꾸지 않는다. F3의 날씨는 예측발행 이전 관측의 지속성 특징이다.
3. 7월 추가 진단: 최근24시간 평균기온과 직전24시간의 차이를 고정 ±2°C로 분할; 요일; 최근24시간/7일 전력비율을 0.8/1.2로 분할; 과거 생산0 비율 및 전력lag2/lag7 불일치. 모든 층과 표본수를 남기고 인과효과로 해석하지 않는다. 실측 기온×생산상태×시간은 사후 분석에만 사용한다.
4. 불확실성: 일별 paired bootstrap(2,000회, seed42)와 전체기간 동일 패턴을 묶는 cluster bootstrap을 함께 제시한다. 패턴 묶기에는 사후 정답이 필요하므로 학습 입력으로 쓰지 않는다. 표본 독립성을 완전히 보장하는 검증은 아니다.
5. 생산량 조건: 시간별 생산량을 4등분한 장부에 예측만으로 정한 기존 이동행렬 R을 적용해 총량 보존을 검사한다. 이 계산은 전력과 생산이 같은 비율로 분할·이동될 수 있다는 가정의 산술적 일관성만 확인한다. 설비 제약·납기·생산량 실현을 입증하지 않는다.
6. 경제성: 위 정책 고정 후 계산. 실제 계측단위·계약·12개월 수요·인건비 정보가 없어 확정 수익을 계산할 수 없다. 확인된 공식 요금만 쓰고, 미확인 단가는 가정 민감도라고 명시한다. 일최대 평균 감소를 월 요금 감소로 바꾸지 않는다. 추가 노동은 변경 전후 차액으로 계산한다.
7. 반대 검토: 과거기간 재사용, 반복자료, Python환경 차이, 일시별 생산0 기록의 의미 불확실성, 가정 기반 이동을 보고서에 남긴다. 성능 향상·생산 보존·이익을 과장하지 않는다.
8. 체크포인트: 전체 예측·지표·실패·명령을 저장하고 GitHub에 커밋/푸시. 공식 평가 6항목 자가점검 2회는 서로 다른 순서와 관점으로 수행하며 외부 독립 심사로 부르지 않는다.

실행: `python -X utf8 research_v4.py audit`, `python -X utf8 research_v4.py benchmark`, `python -X utf8 research_v4.py diagnose`, `python -X utf8 research_v4.py production`.
